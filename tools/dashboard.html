Solace Workload Balancer

Technical status and test controls for ordered event-family routing across three brokers.
How to read this page

Rates are recent messages/second. Target is requested generation; accepted and delivered are observed.

Accepted means the publisher wrote a durable local outbox receipt. It is not a broker ACK.

Backlog is current queue message depth from SEMP meta.count, never the cumulative lifetime spool counter.

Latency is the recent dashboard-observed submit-to-delivery interval. It is not a full distributed trace or SLA.

Order / duplicate checks use a bounded in-memory observation window per run, group, and entity. They do not prove exactly-once delivery.

Assignments are cumulative publisher choices since this dashboard process started; queue rates show current broker activity.

Membership is authoritative control state. ACTIVE serves traffic; epoch identifies the routing generation.

SDKPerf is optional test-only SMF/JCSMP source and sink tooling bridged through the native Go AMQP shims.

        Restricted SDKPerf command terminal
        
This is not an operating-system shell. It executes only the configured SDKPerf binary with validated arguments and shell=False. Pipes, redirects, substitutions, arbitrary hosts, credentials, files, JVM options, and profile options are rejected.

        
Managed mode traverses the Go shims. Type normal SDKPerf arguments; group, entity count, and timeout come from the editable fields above. Supported: -mn, -mr, -msa, plus bounded -ped, -lb, -lg, -psv, -l, -psm, and -soe. Info mode supports -v, -h, -hm, and -he.

        
        
        

        

        

      

    


    

      Direct SDKPerf CLI examples
      
Prerequisites: Java, the official SDKPerf Java package, and private values exported as SDKPERF_CMD, SMF_URL, SDKPERF_USERNAME, VPN, and SDKPERF_PASSWORD. Start the subscriber first.

      
Direct broker smoke test — bypasses the shims. It uses a dedicated topic and does not test Broker 0 discovery or rendezvous placement.

      
"$SDKPERF_CMD" "-cip=$SMF_URL" "-cu=$SDKPERF_USERNAME@$VPN" "-cp=$SDKPERF_PASSWORD" -mt=persistent -stl=swlb-sdkperf/direct-smoke -md

      
"$SDKPERF_CMD" "-cip=$SMF_URL" "-cu=$SDKPERF_USERNAME@$VPN" "-cp=$SDKPERF_PASSWORD" -mt=persistent -ptl=swlb-sdkperf/direct-smoke -mn=100 -mr=25 -msa=256 -ped=2
